# Screenshot Evidence

This folder groups screenshots by source and review purpose. Images have been moved without changing their contents.

## Folders

- [`commands/`](commands/) — command-oriented captures with descriptive filenames.
- [`privilege-evidence/`](privilege-evidence/) — callback and privilege evidence.
- [`terminal/`](terminal/) — timestamped Ksnip captures retained under their original filenames where the visible context was ambiguous or unrelated.

Treat screenshots as supporting evidence. Verify details against the source files and published report before citing a finding.
