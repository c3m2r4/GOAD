# GOAD Red Team Engagement

## Report

The accompanying PDF documents a public red-team engagement against [Game of Active Directory (GOAD)](https://github.com/Orange-Cyberdefense/GOAD). The engagement environment was hosted in AWS. Its stated objectives were to take over the domain controllers and establish reboot-persistent access on `KINGSLANDING`.

The report is provided for public release. Review the PDF for the assessment narrative, evidence, and conclusions.
